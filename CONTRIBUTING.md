# Contributing

1. Keep the mini-program fully runnable from `project.config.json`.
2. Prefer minimal changes and preserve legacy local storage schema/migration behavior.
3. Run all repository tests and syntax checks before submitting PRs.
4. Never attach personal exports, sensitive screenshots, private project settings,
   WeChat credentials, or cloud-related secrets to issues or commits.
5. State whether the change was verified only by automated tests or also in WeChat Developer Tools.
6. Treat original school documents and user-provided screenshots as external materials,
   not project assets that can be copied into this repository without consent.

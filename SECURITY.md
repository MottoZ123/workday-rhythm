# Security and privacy policy

- Do not commit any real AppID, AppSecret, CloudBase env ID, OpenID/UnionID,
  credentials, private project config, screenshots with personal information,
  account/session backups, salary figures, personal calendar entries, or API tokens.
- Repository **source code is not a remote personal-data deletion service**.
  Personal data saved in a previously installed mini-program stays on the device
  until the user invokes the in-app clear/reset action or clears WeChat mini-program storage.
- Share payloads should contain only generic mini-program entry paths; never add
  task, salary, flight, phone, name, or visit-history fields to shares.
- Report vulnerabilities privately to repository maintainers via GitHub security advisories,
  not by posting secrets in public issues.
- Any future service integration needs a separate security/privacy review.

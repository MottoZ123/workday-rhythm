# UI Pixel Reference Spec — V1.1.2

本版本以前期稳定版 UI 的通用风格为设计基准，目标是让**小程序内容区**在常见 375px 宽设备上尽量贴近参考图。微信系统状态栏、胶囊菜单、字体抗锯齿和安全区由设备/基础库控制，因此这些系统像素不做伪造式承诺。

## 1. 基准视觉

- 页面底色：`#FAF4EA` 奶油米白。
- 卡片底色：`#FFFAF2` / `#FFFDF8`。
- 卡片描边：`#EFD6B5`，2rpx。
- 主要文字：`#3F3028`。
- 次级文字：`#8C7969` / `#918178`。
- 鼠尾草绿：`#6C9A61`。
- 暖橙收益：`#EF6F3A`。
- 卡片圆角：主卡 26rpx，内卡 15–19rpx。
- 页面横向留白：28rpx；360px 及以下降为 22rpx。

## 2. 首页结构对齐

1. 顶部不再用厚重 Hero 卡，而是参考图的开放式标题 + 插画区域。
2. 用户提供参考图中的猫/气泡区域被裁切为 `reference-hero-strip.png`，作为视觉基准素材随项目交付。
3. 下班倒计时 / 今日带薪收益使用两列同卡布局，中间暖色竖线。
4. 进度卡使用“今日进度 xx%（已完成 x/x）+ 重置”的单行信息密度。
5. 快捷入口强制分成 2 行 × 2 列，每行两个 `flex: 1 1 0`，不再依赖 `calc(50% - gap)`，解决用户截图中的右侧大面积空白。
6. “今日清单”改成一个外层卡片，分类改为卡内嵌套面板，减少漂浮卡片感并贴近参考图。

## 3. 底部导航

使用微信 `custom tabBar`：

- 奶油白浮层；
- 暖色细描边；
- 顶部圆角；
- 柔和阴影；
- 5 个短标签：今日 / 固定 / 工资 / 统计 / 管理。

## 4. 小屏保护

- 320–360px 不允许快捷入口退化成半宽单列；仍保持两列并压缩字号。
- 所有动态文字区域 `min-width: 0`。
- 自定义摸鱼类型使用 CSS Grid 三列；长标签单行省略。
- 首页任务正文允许自然换行，但右侧状态不挤压正文。
- 动态金额单行省略，防止超大工资输入撑破卡片。

## 5. 不能由代码保证完全一致的像素

- 微信原生状态栏/胶囊菜单位置。
- iOS 与 Android 字体字重、字距、emoji 字形。
- 系统 tab 安全区和底部手势条。
- 不同设备对 rpx 的舍入。

因此“像素级复现”在本项目中定义为：**内容区结构、颜色、比例、留白、圆角、描边、信息层级、插画位置与参考图高保真；系统 Chrome 按真实微信环境适配。**

## 6. V1.1.2 字号与工资设置

- 全局字号三档：Small 保持 V1.1.1 基准；Medium 为默认并将正文通常提升约 2rpx；Large 正文通常提升约 4rpx。
- 42rpx 以上的大数字仅小幅放大，避免工资、倒计时和标题突破卡片边界。
- 工资页四个时间字段固定为 2×2 `CSS Grid`，每格 `minmax(0, 1fr)`，picker 必须 `width: 100%`。
- 工资换算结果固定为 2×2 指标网格，动态金额单行省略；不允许重新使用 `calc(50% - gap)`。
- 320–360px 下仍保持两列时间选择器，因为 `09:00` 和四字标签在安全字号上限内可稳定显示。

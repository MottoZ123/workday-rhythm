# Sanitized source materials

Only `default_categories.snapshot.json` is included as a **generic sample checklist library**.
The original user-supplied HTML, UI screenshots, design studies, and external short links
are deliberately excluded from this public code release.
The in-app `reference-hero-strip.png` has been recreated from the bundled generic
cartoon `cat-lounge.png`; it is not a user-screenshot crop.

No private salary amount, name, user history, WeChat account identifier, or backup JSON is bundled.
At runtime these fields are saved in each device's WeChat local storage by the app.
